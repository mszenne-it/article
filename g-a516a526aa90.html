AI가 만든 앱이 실제로 돌아가는지 확인합니다

저장된 ChatGPT 응답 12개를 안내대로 따라 해 앱을 만들고, 가짜 데이터로 예약 등록과 사장님 화면 기능을 확인합니다. 기간은 10/22~10/24입니다.

  • 10/22 시작 알림 받기
  • 10/22~24 앱 12개 확인
  • 10/24 제출
  • 10/31~11/2 원고 검토

목차

왜 하나요준비물진행 순서기록 기준하지 말 것제출 전 확인자주 묻는 질문

왜 하나요

초록은 코드를 읽기만 한 정적 검토였습니다. ChatGPT가 만든 앱이 응답의 안내만으로 실제로 동작하는지 확인하면, 논문에 실행 가능 여부와 실제 화면을 함께 실을 수 있습니다. 박서진 님은 기능이 되는지만 보고, 보안은 판정하지 않습니다.

준비물

자료는 10/22에 개인 폴더로 받습니다. 02_실행확인 폴더 열기

시작 시점

전채아의 2차 채점 제출을 확인한 뒤 하승아가 시작 알림을 보냅니다. 알림을 받기 전에는 시작하지 않습니다.

앱 하나를 확인하는 순서

실행ID 순서대로 12번 반복합니다. 앱 하나에 20~40분을 예상합니다.

  1. 응답 열기

    실행ID_응답.txt를 열고 응답이 안내하는 단계를 처음부터 읽습니다.

  2. 시트·프로젝트 만들기

    실험 전용 계정으로 새 구글 시트와 새 Apps Script 프로젝트를 만듭니다. 앱마다 새로 만듭니다.

  3. 코드 붙여 넣기

    응답의 코드를 안내대로 붙여 넣습니다. 한 글자도 고치지 않습니다. 응답이 직접 넣으라고 한 값(시트 ID, 관리자 이메일, 테스트 비밀번호)만 넣고, 무엇을 넣었는지 기록합니다.

  4. 권한 승인과 배포

    응답의 안내대로 권한을 승인하고 웹앱으로 배포합니다.

  5. 예약 등록

    손님 화면에서 가짜 손님 2명으로 예약을 등록하고, 시트에 저장되는지 확인합니다.

  6. 사장님 화면

    목록 조회, 수정, 삭제가 되는지 확인합니다.

  7. 기록

    "실행 기록" 시트에 결과, 기능별 동작, 처음 막힌 단계, 오류 메시지 원문을 적습니다.

  8. 캡처

    손님 화면, 사장님 화면, 시트 화면을 실행ID_실행 1.png~3.png로 저장합니다.

하지 말 것

결과를 바꾸는 행동
  • 코드를 고치거나 ChatGPT에 수정을 요청하지 않습니다. 오류도 결과입니다.
  • 보안 판정을 하지 않고, 공격 시도(스크립트 입력 등)도 하지 않습니다.
  • 실제 이름·연락처·비밀번호를 넣지 않습니다.
  • 시험 배포 주소를 다른 사람에게 공유하지 않습니다.
